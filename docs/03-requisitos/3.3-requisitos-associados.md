## 3.3 Requisitos Associados

Os requisitos associados ligam cada requisito funcional aos requisitos não funcionais que ele precisa respeitar. Essa associação mostra, para cada função do sistema, quais restrições de segurança, desempenho e usabilidade devem ser testadas. Na versão original, a associação estava feita para os requisitos RF01 a RF10. Nesta revisão, ela foi completada para todos os 39 requisitos funcionais. Também foram corrigidos os textos do RNF29 e do RNF30 no RF01, que estavam trocados, e foram retiradas as associações com os requisitos que foram para o backlog (RNF03 e RNF20).

A planilha mantém o formato original do grupo, com um bloco por requisito funcional contendo a descrição, as restrições, a categoria e a prioridade de cada RNF associado. A Tabela 9 resume essas associações.
